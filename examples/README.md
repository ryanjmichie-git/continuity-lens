# Demo media

Add six owned or appropriately licensed qualitative examples locally. Video files are ignored by Git.

Recommended coverage:

1. Continuous human or object motion.
2. Same-scene temporal jump.
3. Subject-identity inconsistency.
4. Geometry or object-permanence failure.
5. Intentional stylistic cut.
6. Fast camera motion that may fool optical flow.

Record provenance and permission outside the public repository before using any clip in a demo video.
